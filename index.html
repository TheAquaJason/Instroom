🚀 Hoe host je dit op onrender (mmmclub.onrender.com)?

Render.com biedt gratis statische sites aan via GitHub. Volg deze simpele 3 stappen:

  1. Sla dit bestand op: Kopieer deze volledige HTML-code en sla hem op als index.html in een lege map.
  2. Zet op GitHub: Maak een gratis GitHub repository aan (bijv. mmmclub) en push deze index.html erin.
  3. Koppel aan Render:
    • Ga naar dashboard.render.com.
    • Klik op New + > Static Site.
    • Selecteer jouw GitHub repository.
    • Vul bij Name in: mmmclub (zodat je URL automatisch mmmclub.onrender.com wordt mits die nog vrij is!).
    • Publish Directory: laat leeg of typ . (punt).
    • Klik op Create Static Site. Binnen 30 seconden staat je one-pager live!
